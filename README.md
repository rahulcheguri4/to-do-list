📝 Simple To-Do List Application

A beginner-friendly To-Do List application built using Python. This project allows users to add, view, complete, and delete tasks through a simple command-line interface.

🚀 Features
➕ Add new tasks
👀 View all tasks
✅ Mark tasks as completed
🗑️ Delete tasks
⚠️ Handle invalid user input
🚪 Exit the application
🛠️ Technologies Used
Python 3
--Lists
--Dictionaries
--while loops
--Conditional statements
--enumerate()
--append()
--pop()
Exception handling (try / except)
